# Tecnologías del proyecto — Studio Milano

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## 1. Herramientas que voy a utilizar

| Área | Herramienta | ¿Para qué la voy a utilizar? |
|---|---|---|
| Construcción | HTML y CSS | Para crear las páginas del sitio web, organizar la información y definir los colores, las letras y el diseño. |
| Versionado | Git y GitHub | Para guardar los cambios del proyecto y mantener una copia del código en internet. |
| Publicación | GitHub Pages | Para publicar el sitio web y permitir que otras personas puedan visitarlo. |
| Diseño | Whimsical | Para crear los bocetos y organizar cómo se verá el sitio antes de programarlo. |
| Prototipo | Google Stitch | Para crear una propuesta visual del sitio web de Studio Milano. |
| IA y editor | ChatGPT y Visual Studio Code | Para recibir ayuda con ideas y código, y escribir y editar los archivos HTML y CSS. |

## 2. ¿Qué funcionalidades serán reales y cuáles serán prototipos?

Como el sitio se realizará con HTML y CSS, algunas funciones podrán utilizarse de verdad, mientras que otras serán solamente una muestra visual.

| Funcionalidad | Tipo | Cómo funcionará |
|---|---|---|
| Navegar entre páginas | Funcional | Permitirá cambiar entre las secciones del sitio. |
| Ver los servicios y precios | Funcional | Mostrará los servicios de uñas y sus precios. |
| Ver fotografías de diseños | Funcional | Permitirá ver los trabajos realizados por Studio Milano. |
| Contactar por WhatsApp | Funcional | Abrirá WhatsApp mediante un enlace directo. |
| Acceder a Instagram | Funcional | Permitirá visitar el perfil del emprendimiento. |
| Buscar servicios | Prototipo visual | Se mostrará un buscador, pero no realizará búsquedas reales. |
| Filtrar diseños | Prototipo visual | Se mostrarán opciones de filtros, pero no estarán programadas. |
| Reservar una hora | Prototipo visual | Se mostrará un formulario de reserva, pero no guardará los datos ni confirmará citas. |
| Dejar el correo para recibir ofertas | Prototipo visual | Se mostrará un formulario, pero no almacenará los correos. |
| Comentar artículos | Prototipo visual | Se mostrará la sección de comentarios, pero no permitirá publicar comentarios reales. |
| Recibir recordatorios | Prototipo visual | Se mostrará la opción, pero no enviará notificaciones. |

## 3. Integraciones necesarias para una versión real

Si Studio Milano quisiera tener un sitio completamente funcional, necesitaría herramientas adicionales:

- **Reservas online:** Un sistema de agenda para administrar los horarios y confirmar las citas.
- **Formularios:** Un servicio que permita guardar las solicitudes de reserva y los correos de las clientas.
- **Email marketing:** Una herramienta para enviar promociones, descuentos y novedades.
- **Comentarios:** Un sistema que permita publicar y administrar comentarios en el blog.
- **Pagos online:** Una pasarela como Webpay o Mercado Pago, si se quisiera recibir pagos o abonos por internet.

*Estas integraciones no serán necesarias para la primera versión visual del proyecto.*

## 4. Plazo y restricciones

- **Plazo:** 2 a 3 semanas para diseñar, desarrollar y publicar el sitio.
- **Identidad de marca:** Se definirá una propuesta visual propia para Studio Milano, con colores, tipografías y un estilo relacionado con la manicura.
- **Dispositivos:** El sitio estará pensado para computadores y celulares.
- **Tecnologías:** Se utilizarán HTML y CSS, sin frameworks ni gestores de contenido.
- **Publicación:** Se utilizará GitHub Pages para mostrar el proyecto en internet.
- **Limitaciones:** Las funciones que necesiten guardar datos, procesar reservas o enviar mensajes no estarán operativas en esta primera versión.

**Objetivo final:** Crear un sitio web atractivo y fácil de usar para Studio Milano, donde las clientas puedan conocer los servicios, revisar los precios, ver diseños y acceder al contacto por WhatsApp.
